# Turnbased: CLI Fighter

A small turn-based fighting game for the command line. Pick a fighter, then take on a randomly selected rival. Attack, guard against the next hit, or unleash a signature move that recharges after two turns.

## Fighters

- Lee Yung: Dragon Kick
- Ellie Shade: Shadow Strike
- Jax: Thunder Smash
- Kageyama: Void Slash

## Play

Requires Python 3. Run:

```bash
python3 game.py
```
